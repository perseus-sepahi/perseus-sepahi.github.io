This site is the front door for everything I release: apps for Mac, iPhone and Apple Watch, research papers, and my thesis.

The source code for projects lives on GitHub. This site is where you find the **download**, the **screenshots**, and the **paper** without digging through repositories.

## How it is built

The whole site is static HTML generated by a small Node script from JSON files. Adding an app means adding one JSON file in `content/software/` and running `npm run build`. Deployment happens automatically on push through GitHub Pages.
